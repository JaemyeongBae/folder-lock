# Windows 실기 테스트 체크리스트

**반드시 테스트용 폴더로만 진행한다.** 예: `C:\잠금테스트\샘플`에 아무 파일이나 복사해 넣고 시작.
문제가 생기면 `%APPDATA%\FolderLock\log.txt`를 보내 주면 된다.

## 준비
- [ ] `FolderLock.exe`를 `C:\Tools\` 같은 곳에 둔다 (잠글 폴더 밖).
- [ ] 처음 실행 시 SmartScreen 경고가 뜨면 "추가 정보 → 실행".
- [ ] 한글이 제대로 보이는지 (맑은 고딕).

## 기본
- [ ] [폴더 추가] → 테스트 폴더 선택 → 비밀번호 두 번 입력 → 목록에 "열림"으로 표시
- [ ] [잠그기] → 탐색기에서 폴더를 열면 `잠금 해제.exe`만 보임
- [ ] 탐색기 "숨긴 항목 표시"를 켜도 보관 폴더(.folderlock)가 안 보임
- [ ] 폴더 옵션에서 "보호된 운영 체제 파일 숨기기"를 끄면 `.folderlock`이 보이지만, 더블클릭하면 "액세스 거부"
- [ ] `.folderlock`을 삭제하거나 이름을 바꾸려 하면 거부됨
- [ ] 앱에서 [잠금 해제] → 틀린 비밀번호는 거부, 맞으면 파일이 원래대로 (내용·하위 폴더·날짜 확인)
- [ ] 해제 후 `잠금 해제.exe`와 `.folderlock`이 남아 있지 않음

## 폴더 안의 잠금 해제.exe
- [ ] 잠근 뒤 폴더 안 `잠금 해제.exe` 더블클릭 → 비밀번호 창이 바로 뜸 (**한글 이름 exe가 정상 실행되는지 확인**)
- [ ] 해제하면 탐색기로 폴더가 열리고 `잠금 해제.exe`가 지워져 있음
- [ ] 앱 목록에 그 폴더가 등록되어 있음

## 안전 상황
- [ ] 폴더 안 Word/Excel 파일을 연 채로 [잠그기] → 오류 메시지가 나고 모든 파일이 원래대로 있음
- [ ] 잠긴 동안 폴더 안에 새 파일 `a.txt`를 만들고, 원래도 `a.txt`가 있었다면 → 해제 후 `a.txt`(새 파일)와 `a (복원 1).txt`(원래 파일) 둘 다 있음
- [ ] 금지 폴더 거부: 바탕 화면 자체, 문서 자체, `C:\`, OneDrive 아래 폴더, USB 메모리 폴더
- [ ] 바탕 화면 **아래의 하위 폴더**는 잠글 수 있음
- [ ] 잠긴 상태에서 [비밀번호 변경] → 새 비밀번호로만 풀림
- [ ] 큰 폴더(수 GB, 파일 수천 개)도 잠그기·풀기가 1초 안팎으로 끝남 (이름만 바꾸므로)

## 강제 종료 (선택)
- [ ] 잠금 중 작업 관리자로 강제 종료하기는 너무 빨라 재현이 어렵다. Mac 자동 테스트가 모든 단계를 대신 검증했다.

## 알려 줄 것
